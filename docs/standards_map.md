# Standards map

Every sanitization claim carries its clause. An officer reads this table before
they read the code.

Sources cited, never paraphrased: NIST SP 800-88 Rev. 1 (Clear / Purge / Destroy),
IEEE 2883-2022, and DoD 5220.22-M where legacy expectation demands it.

| Our operation | Standard | Clause | What we verified | What we could not verify |
|---|---|---|---|---|

A row is added when the operation is implemented and its verification has actually
run. The final column is never empty: an operation with nothing in it has not been
examined honestly enough yet.
